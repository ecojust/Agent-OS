# Agent OS

一个以 Agent 为交互入口的 Android 定制系统项目：用户在手机内配置模型地址、密钥和模型，通过对话让 Agent 在授权范围内操作手机应用。

**当前阶段：功能规划与架构设计。** 本次提交不包含可安装应用或可刷写系统镜像，也不代表已完成真机适配。

首版面向**手机已解锁、操作过程可见**的场景。先以 Android 执行器验证跨应用任务，再将成熟的任务服务、执行能力和交互入口集成到 AOSP 系统。

## Planned Capabilities

| 模块 | 规划能力 |
| --- | --- |
| 对话入口 | 输入任务、查看步骤、处理确认、暂停与停止 |
| 模型接入 | 在手机内配置服务地址、密钥和模型；首版接入兼容 Chat Completions 工具调用的服务 |
| 应用操作 | 打开授权应用、读取界面、点击、输入、滚动、手势与按需截图 |
| 执行与验证 | 每次动作校验当前界面，操作后重新观察，区分操作已提交与目标已完成 |
| 用户控制 | 应用授权范围、逐步确认、截图确认、锁屏停止、任务预算 |
| 系统集成 | 后续接入系统服务、对话桌面和经过真机验证的 ARM64 设备支持 |

模型默认运行在用户配置的服务端；任务调度、设备操作和执行控制运行在手机端。界面结构或经确认的截图会发送到所配置的模型服务。

## Roadmap

1. **设计基线**：明确产品范围、模块边界、执行流程与验收标准。
2. **可安装原型**：验证手机端模型配置、可见执行、应用范围和取消机制。
3. **可靠执行**：完成真实跨应用任务、异常恢复与不同 Android 版本测试。
4. **系统集成**：选择参考手机，将执行能力接入 AOSP 并制作机型适配版本。
5. **设备扩展**：维护已验证机型列表，评估符合条件设备的通用系统镜像。

首个系统镜像以 ARM64 为目标。具体手机的启动、相机、通信、指纹和功耗需要分别适配与测试；不承诺一个镜像兼容所有 ARM 手机。
