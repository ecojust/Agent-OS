# Android 原型使用说明

当前交付是安装到现有 Android 系统上的调试 APK，不替换手机系统，也不是刷机镜像。最低 Android 11；具体厂商手机和真实模型服务仍需验证。已完成和待完成能力见 [实现状态](../IMPLEMENTATION.md)。

## 安装与配置

1. 在[当前验证概况](../IMPLEMENTATION.md#当前验证概况)核对源码与结果，再从对应的 [Android checks](https://github.com/ecojust/Agent-OS/actions/workflows/android.yml) 运行下载 `agent-os-debug-<提交号>` 产物，解压后安装。单项诊断通过、构建成功或操作演示通过均不代表整套测试通过；尚有失败的提交按开发版本对待。产物采用开发签名，通常保留 14 天，下载可能需要登录 GitHub。
2. 打开 Agent OS，展开“模型连接”，填写兼容 Chat Completions 的模型服务地址、模型名称和密钥。密钥只在手机内填写，不需要提交到仓库。
3. 点击“测试模型连接 / 工具调用”。“测试图像理解”是另一项可选测试，只上传临时生成的色块图，不读取手机屏幕；这两项结果分别显示。测试可以取消，修改连接字段会清除旧结果。本机或局域网 HTTP 地址会显示传输提示，需要核对地址后继续。
4. 点击“选择应用”，选择这次允许读取和操作的应用。在“执行模式”中保留默认的“逐步确认”，或主动选择“连续导航”，再点击“保存模型与授权设置”。模式在保存或开始任务时生效；保存配置会使旧任务和旧动作确认失效。
5. 点击“前往开启无障碍服务”，在系统页面手动启用 Agent OS 的服务，然后返回应用。授权入口和安装限制因厂商系统而异；未获得授权时，应用不会开始设备操作。

模型连接中的“每次回复上限”可设为128–8192个Token，默认2048，任务和模型测试都使用此值。它是发送给服务端的单次输出限制，不是累计用量或费用上限；服务端是否支持该参数仍以实际连接结果为准。

## 执行与接管

保持手机亮屏、解锁并连接 Wi-Fi，在任务输入框填写一个简单目标，例如“打开我选择的应用，读取当前页面并停下”，点击“开始执行任务”。首版无需 SIM 卡，也不申请电话或短信权限。

“任务预算”收起时显示当前选定的轮次、工具次数与活动时间，展开后可修改：模型轮次 1–300、工具调用 1–1000、活动时间 1–3600 整秒。默认仍为 30 轮、100 次、600 秒。保存设置或开始任务时生效；非法或空值会在对应字段提示并阻止保存、启动。达到任一上限即停止，已完成的操作不会撤销。暂停、等待确认不计入活动时间，但暂停继续不会重置已用次数；排队和模型等待计入活动时间。运行、模型测试或正在保存时不能修改预算，任务日志会记录实际生效值。

默认“逐步确认”会在每次界面操作前请求确认。用户可在本机选择“连续导航”：只有打开已授权应用（`launch_app`）、滚动（`scroll`）和回到桌面（`home`）免逐次确认；返回（`back`）、点击（`click`）和输入（`type_text`）仍需确认。应用授权、当前界面和提交前检查在两种模式下都保留，模型不能更改执行模式。旧版本配置不会自动启用连续导航，即使旧配置中的确认开关曾设为关闭，也会按逐步确认读取。

需要确认时，核对目标应用和动作内容后选择“允许这一次”，或使用“拒绝当前动作”。确认只有一次有效，默认 60 秒超时；界面或配置改变后，旧确认不能继续使用。无法观察的页面会返回限制，不会自动改用截图或坐标手势。

执行控制条提供“暂停”和“停止”；上方状态区域可拖动，触控高度至少48dp，读屏描述会包含当前任务状态。暂停后只有用户选择“继续”才会重新观察并规划；停止结束本轮任务。已经进入系统调用的动作可能仍在完成，需要核对手机实际状态，不能把停止视为撤销。模型最终报告同样需要结合实际结果判断。

本次任务用量区域显示模型轮次、工具调用及剩余活动时间，暂停和等待确认单独计时。结束后保留固定统计，清空本页或开始新任务后替换；工具次数包含观察和已计数的失败请求，不表示完成操作数。

## 查看操作回执

任务结果区的“操作回执”显示本次任务实际送入执行通道的打开应用、点击、输入、滚动、返回和回到桌面请求。它区分未提交、系统接受、系统未接受及回执不完整；**系统接受动作不等于目标完成**，模型最终文字仍是待核对报告。

打开后显示固定快照；关闭后再次打开可查看后续记录。重复调用同一个请求不会新增一条实际操作记录，观察和等待等只读工具也不列入。最多保留最近200项，较早的省略数量会明确显示，不能将列表长度当作成功动作数。

停止或配置失效时，尚未取得最终回执的请求保持未知，请到目标应用核对，勿据此重复操作。任务结束后保留本次记录；清空本页、开始新任务或进程退出后移除。回执只含固定动作类别和状态，不含输入文字、应用内容、模型回复或连接密钥，不提供重放按钮，也不写入历史文件。

## 数据与验证范围

“清空本页任务内容”清理本轮界面结果；“重置本机配置”用于用户明确删除本机配置。连接信息使用本机加密存储，任务与观察内容默认不保存为历史文件。

“设备与兼容性”显示当前系统条件，可用于后续登记真实手机测试结果。模拟器测试使用合成应用和本地测试服务；不能以诊断页或连接测试通过，推断任意第三方应用、真实模型或手机已经完成兼容性验收。


任务结果区的“任务诊断”可以预览并复制本次任务的固定状态和用量报告；活动任务仍可从弹窗中停止。报告不包含任务正文、密钥、模型地址或原始日志。清空本页或开始新任务后，旧报告失效；已经主动复制到系统剪贴板的文本由用户管理。
