# Official Notes APK inspection

Local inspection of the unmodified official Notes 1.7.0 APK. The release asset size and SHA-256 were checked before Android SDK Build Tools 35.0.0 verified its signature and read its manifest. Metadata and complete tool outputs are retained here; the APK is not redistributed in this repository.

This is an APK identity inspection, not a device test, installation result, screenshot, or application compatibility acceptance. The reviewed certificate can be frozen in the separate developer-probe sample; every device run must independently verify the same bytes and installed identity.
