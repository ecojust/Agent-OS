# 配置读取失败的手动恢复

本模块落实设计规则R6、R8、R9：读取失败保留配置，提供明确的恢复步骤，无法识别的较新格式不覆盖。已有加密存储、配置许可和原子保存继续使用；本轮没有引入新的配置格式或数据迁移。

## 固定范围

- 仅在配置读取失败时显示“保留配置并重新读取”。每次点击只提交一次本机读取，忙碌、模型测试或任务运行时拒绝重入，不请求模型、不执行设备动作。
- 错误按固定类型提示，不展示底层异常或配置内容。配置版本只接受整数；较新的整数版本提示使用兼容应用，字符串、小数、布尔值等不转换成受支持版本。
- 重读不写入配置或创建替代密钥。未知格式、无法解密及错误版本保持原副本；存储写入结果无法确认的锁定继续要求明确重置，不能用重读解除。
- 读失败撤销旧配置许可，恢复有效副本后需要重新验证并取得新许可。界面重读不恢复旧任务、旧确认或旧模型探测记录。
- 手动读取绑定当前页面代次；离页、销毁或代次失效后，迟到结果不回填。返回页面不自动重读。首次启动读取仍由原启动流程执行。
- “重置本机配置”保留独立删除确认，配置页继续启用`FLAG_SECURE`；不添加截图例外。
