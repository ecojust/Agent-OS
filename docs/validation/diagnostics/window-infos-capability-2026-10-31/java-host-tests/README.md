# WindowInfos capability: controlled host validation

The runner compiles both actual new Java sources against controlled Android/JUnit
substitutes and six public API fixture variants. It checks 81 properties: the fixed
27 public lookup slots; no class initialization during those lookups; one ForTest
constructor after all lookup slots; no WindowInfo/DisplayInfo initialization or
listener method invocation; exact modifier/type mismatches; public missing/filtered
observations; source-unlisted gap fields without invented expected types; abstract
class refusal; constructor failure; deadline interruption between operations; and
gates that prevent any reflection operation on invalid opt-in/API/source arguments.
It also executes the actual instrumentation test entry against the substitutes and
checks its explicitly bound status-2 marker, metadata bounds and permission status.

The fixtures are not Android implementations. They cannot establish Android TestApi
visibility, hidden-API policy behavior, real construction behavior, app permissions,
SurfaceFlinger access, listener registration or window contents. Default Android
instrumentation may already have a TestApi exemption; the probe asks for no additional
exemption. Its policy label deliberately says
`PUBLIC_WHITELIST_ONLY_NO_ADDITIONAL_EXEMPTION_REQUEST`.

`synthetic-java-python-report.json` is the actual Java-produced report from a controlled
host execution, wrapped with `synthetic: true`. Its API37, UID, target SDK, build data,
source SHA, run ID and serial are stub values for parser cross-validation, not device
or GitHub-run evidence. The 27 lookup results and constructor result are generated by
the real helper; the report is not a hand-written success receipt.

Requires Java 17 and `org.json:json:20240303` from
https://repo.maven.apache.org/maven2/org/json/json/20240303/json-20240303.jar .
The runner verifies SHA256
`3cf6cd6892e32e2b4c1c39e0f52f5248a2f5b37646fdfbb79a66b46b618414ed`.
The dependency binary is neither committed nor downloaded by this test.

```sh
python3 docs/validation/diagnostics/window-infos-capability-2026-10-31/java-host-tests/run.py --java-home /path/to/jdk17 --json-jar /path/to/json-20240303.jar --cross-output /tmp/synthetic-capability.json
```

The helper's 5000 ms deadline is checked between reflection operations; it cannot
interrupt an operation already in flight. The real runner supplies the outer process
timeout. A completed catalog inspection is separate from public-surface matching,
construction success, permission status and unattempted listener registration.
