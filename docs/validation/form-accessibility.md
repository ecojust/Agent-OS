# 原生表单可访问性

本模块落实[设计规则 R8](../DESIGN_RULES.md#r8-统一交互与可访问性)中的读屏标签与导航语义，范围为主页面。它不代表已经完成真实读屏服务、厂商设备、旋转或多窗口验收。

## 行为范围

- 模型地址、模型名称、API 密钥、每次回复 Token 上限、模型轮次、工具调用、活动秒数及任务输入分别关联自己的可见标签。填写内容后仍保留标签关系；输入框继续使用原生编辑语义，不用固定内容描述替代输入值。
- 主页面分区标题提供原生标题语义，便于支持该功能的辅助服务导航；保留原有界面顺序。
- 模型设置和任务预算按钮分别报告实际展开或折叠状态；按钮文字继续说明下一步操作。
- 密钥显隐按钮使用固定的操作和状态文字，不拼接密钥。默认隐藏，用户可以主动显示并再次隐藏；原有密码输入类型、禁止保存、禁止自动填充与安全窗口保持。
- 这些交互不保存配置、不发起模型请求、不开始任务，也不改变预算、授权或执行条件。

## 验证边界

设备测试使用专用模拟器、实际附着的 Activity 和 UiAutomation 返回的平台无障碍节点，核对标签关系、标题、状态与实际按钮操作。节点验证与真实 TalkBack 的朗读、焦点导航及与其他辅助服务共存不同，后者仍待专项验收。

新增 `MainActivityAccessibilityInstrumentedTest` 的三项固定用例：

| 用例 | 核对行为 |
| --- | --- |
| `filledEditorsPublishRealLabelRelationshipsWithoutSavingOrStartingWork` | 通过实际节点填写八个输入，验证填写后双向标签关联与固定标签文字，编辑值仅在内存 |
| `remoteHeadingsAndCollapseActionsExposeCurrentStateAndVisibleChildren` | 六个分区节点的标题语义，以及真实展开、收起动作后的状态、动作文字与子控件可见性 |
| `remoteKeyActionsAndRealRecreationKeepFixedDescriptionsAndRemaskTheDraft` | 真实显示、隐藏操作及 Activity 重建后重新隐藏；保留原输入类型，按钮只提供固定元数据 |

默认和重新隐藏时验证密码节点；主动显示后沿用平台原生编辑行为，不要求无障碍节点继续报告密码遮罩。测试同时核对配置副本、控制器和本地模型服务，避免把编辑表单变成保存、请求模型或开始任务。

含合成密钥及输入内容的页面保留安全窗口；不尝试截图、不导出整棵节点树，不新增空页面截图例外。逐案保留保护性未采集原因，不将其计为测试跳过。
