# Notes 创建对话框确认：独立 v4 契约

## 实测依据与范围

[v3 诊断轮](notes-preparation-diagnostics.md)仍为22/32。API31–34的确认按钮与已验证输入法矩形相交64×27像素；API35精确匹配一个按钮资源，但可见匹配为零。既有完全无遮挡判定应继续拒绝这些目标。v3禁止自动BACK，因此本轮另立v4契约，保留v3两轮及v2历史结果，不将新旧轮次合并。

本轮仍使用未修改的 Calculator 1.4.0、Notes 1.7.0，八档API30–37、服务关闭/空闲两态，共32项。APK来源、大小、哈希、签名和四个真实测试方法不变；当前清单、设备标记、采集/归档schema及产物名称明确版本化为v4。历史归档继续按各自测试源码解释。

只修改专用合成模拟器上的测试探针，不修改Agent产品工具、权限、确认策略或第三方APK。初始编辑、正文输入与回读沿用允许已验证IME存在但目标必须完全无遮挡的规则；正常HOME保存仍最多一次，随后停止旧进程并重新启动核对完整标题/正文。

## 仅确认创建前允许一次收键盘

这是对可见键盘的一次普通返回导航，不保证系统接受后键盘一定隐藏，也不能撤销已提交的事件。固定 Notes 的[创建回调](https://github.com/FossifyOrg/Notes/blob/786fc41f68d1aed8d82144a6de0127ed4dbe8b61/app/src/main/kotlin/org/fossify/notes/dialogs/NewNoteDialog.kt#L29)仍由确认按钮触发；通用对话框可取消，因此返回也可能关闭对话框，必须验证后置状态。

1. 标题输入与文字类型选择结束后，创建一个5秒准备上下文。通过原窗口身份与遮挡守卫，取得唯一的 `locked_note_title`；核对当前窗口、可见、可用、可编辑、非密码、完整无遮挡矩形及完整合成标题。将发送BACK时另须核对实际输入焦点；没有键盘且不发送BACK的路径不强求输入焦点。记录原对话框窗口编号，不主动改变焦点。
2. 本专项在同默认显示屏和原层级过滤之后，识别已配置且启用的系统IME，即使其矩形位于对话框之外也不能当成键盘不存在。仍执行原服务权限、系统身份、实际根/窗口及几何校验；普通编辑与截图的窗口读取不改变。当前已验证IME存在时，要求锚点与几何稳定600毫秒，窗口管理器两次正向可见且无动画的采样至少相隔150毫秒。每次shell读取后重取实际应用、标题和IME；未知窗口或身份仍立即拒绝。
3. 仅在全部条件仍成立时，在按下前消耗本轮唯一BACK额度。分别记录按下/抬起是否被系统接受；部分提交或异常仍占用额度，不重发。配对抬起用于结束已开始的按键，不重新创建一次导航。
4. 若准备时IME已不在窗口列表中，不发送BACK，仍须完成下述正向隐藏验证。窗口列表未出现IME本身不证明隐藏。
5. 重新核对原对话框窗口编号、精确标题与全文，再取得唯一确认按钮。对话框消失、窗口编号改变或标题改变即拒绝，不能在其他窗口寻找同名按钮继续。确认按钮必须可见、可用、可点击、非密码、完整在应用窗口内且完全无遮挡；IME区域必须为空。
6. 新几何稳定600毫秒后，复用既有严格解析器取得两次同身份的正向隐藏采样，间隔至少150毫秒。每次shell后重新读取实际窗口、标题、按钮及IME；变化废弃就绪状态。最终仍满足期限与全部条件，才点击一次确认。

标题输入焦点是BACK前需要实测的条件，不能据固定应用源码假定点击文字类型后仍保有焦点。这些检查也不证明IME内部输入连接一定绑定该标题，BACK仍可能关闭对话框；后置身份检查必须阻止继续。隐藏后以原对话框与完整标题作为身份锚，不把焦点保持不变当作创建成功。键盘再次出现或对话框发生变化会拒绝确认，不通过额外BACK、焦点动作、坐标点击或重新创建来补救。

## 固定预算和记录

准备、单次BACK、隐藏验证及最终确认共用首次创建的5秒期限，不续期。正向可见采样最多4次，正向隐藏采样最多4次，总计最多8次窗口管理器读取；这是v4显式新增的读取预算，不宣称与v3的4次预算相同。就绪状态变化不会恢复采样或动作额度。

每轮准备、阻塞读取边界与新动作提交处核对期限，过期后不提交确认。同步平台调用自身可能越过期限，返回后记录失败；本地时限不是与系统调用的原子保证。唯一收尾例外是已经开始的BACK按下：即使同步返回时已过期或接受状态未知，仍最多尝试一次同键配对抬起，分别保留其结果；这不续期，不允许新的按下或确认。读等待不重放标题输入、类型选择、BACK或确认。

结果分别记录BACK尝试及按下/抬起接受、正向隐藏检查、原对话框约束和确认提交。通过必须有完整后置证据，不能只凭BACK被接受或确认点击返回成功。失败保留partial/null和实际计数，包括违反预算的原记录；归档不能丢弃失败以提高通过率。普通截图仍要求既有正向隐藏与窗口保护检查，不为图片再收键盘或清除安全标记。
