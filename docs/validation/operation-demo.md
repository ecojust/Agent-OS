# 整体操作演示

演示录像由专用 Android API 35 模拟器直接录屏取得，配套测试调用真实执行器、已保存的加密配置、真实手机控件及当前确认按钮。模型回复来自本地确定性 HTTP 测试服务，目标应用只含合成数据；它展示执行链和用户接管，不证明真实大模型理解、第三方应用兼容或真机性能。

## 本轮验收目标

| 阶段 | 画面与实际结果 |
| --- | --- |
| 输入与保存 | 逐步确认后输入合成文字、点击保存、将计数增加一次；独立读取界面核对结果 |
| 页面导航 | 确认滚动下移、上移、打开第二页和返回，重新观察页面并验证原数据仍在 |
| 用户控制 | 在待确认时点击暂停、继续、停止；暂停与停止期间不派发动作，恢复后的确认不得复用旧执行代次 |

录像从预先配置好的测试状态开始，不打开受保护的密钥配置或图片审阅页面，不清除 `FLAG_SECURE`。界面停留和录像只是便于观看，测试结论来自真实状态与动作结果的断言。点击使用当前附着按钮的真实监听器，不替换回调、不用示意图冒充操作画面。

单次操作流程最多90秒，外层录制最多120秒，停止只针对本轮创建的录屏进程。输出为可完整解码的 H.264 视频，严格小于100,000,000字节，并保留时长、尺寸、哈希、源码及运行信息。压缩保持原始过程和时序，不拼接虚构场景。视频本身不包含旁白。

## 运行与归档

使用仓库的 `Record and archive an actual walkthrough` 工作流：`mode=test` 构建并录制；完成后用 `mode=archive` 和原运行编号归档。归档限定本仓库主分支的专用录制任务，复核原运行、源码、attempt、产物、逐项结果和文件校验值。

每次真实运行都保留结果，包括失败、缺失或受保护的捕获。原始 Android 流程记录、截图清单和实际视频放入 `screenshots/demos/<run>-<attempt>/`。README 只将验证成功的真实视频设置为“整体操作演示”，显示其确切源码；失败记录不覆盖上一段成功录像，也不被删除。构建脚本或归档代码的更新不意味着已经重录。

本文件说明验收契约；当前可播放录像和实际结果以 [README](../../README.md) 及对应清单为准。

第二轮实际运行在初始观察阶段失败，未派发操作；原始结果和失败截图保存在 `screenshots/demos/40517744028-1/`。显示覆盖后出现1像素边界差异的线索，尚不能仅凭日志认定首因。后续录制复用主测试矩阵已使用的原生模拟器几何，不在启动后覆盖尺寸或密度；仅在原观察期限失败后读取控件几何诊断，不放宽判断条件。

录制报告保留最早失败与最多8条后续阶段错误，单独收集最多8 KiB的录屏进程错误输出，区分拉取、探测、编码与解码失败。旧记录保持可读；成功录像仍需完整解码、操作结果校验以及严格小于100 MB，不能由诊断字段替代。
