## 新增事实与结论边界

API32 的候选1与冻结 drawingTime 属于同一VSYNC毫秒，但四段UI时长均为0，DRAW_START等于VSYNC并早于OnDraw；候选0则是更早VSYNC的延迟报告。后续保留候选的真实DRAW_START已晚于原读取区间。API30候选0的四段UI时长也全为0：虽然推导DRAW_START恰落在OnDraw/read区间，却等于其VSYNC且VSYNC毫秒不同，不能用它补齐首停止traversal。

上述全零UI阶段与AOSP RT合成时序构造相符，是前三轮原件所没有的新直接数据；v2没有再把它们误记为目标或报告旧帧歧义。它们仍不能独立证明原UI traversal是否提交后被跳过、具体显示内容或哪个buffer成功提交。其余未保留候选仅有全程质量计数，不能补造逐条原值。

因此当前仍缺首停止traversal对应的公开FrameMetrics证据，不能关闭专项，也不宜据本轮启动正式1600次采样。保持原方法、固定分母和首draw要求，不替换为后续更容易关联的帧。
