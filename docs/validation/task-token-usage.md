# 本次任务服务端 Token 用量

本模块落实设计规则R5的用量未知标识，在原任务用量区域展示服务端报告的输入、输出和总计。它不增加计价、累计Token预算或自动重试；现有每次模型回复上限仍是独立的服务端限制请求。

## 固定统计口径

- 每次进入统一HTTP网关并通过原上下文检查的逻辑调用，只登记一个绑定原RunControl和执行代次的票据。统计分母是本机请求调用，可能尚未发往服务端，不等于模型轮次、服务器收到次数或计费次数。
- 普通任务请求、任务内合成图像探测经过同一入口；独立配置测试使用自己的RunControl，不混入当前任务。统计只保留有界字段和计数，不保留响应、页面、地址、密钥或每次请求历史。
- `prompt_tokens`、`completion_tokens`、`total_tokens`分别接受非负、十进制整数JSON数值，范围不超过有符号64位整数。字符串、小数、指数表示、负数、缺失或非法字段为未知，真实有效0保留。不从其他字段推算缺失项。
- 已知总计小于输入或输出，或三个字段齐全但总计与输入加输出矛盾时，该次用量整体未知。重复顶层`usage`或重复已知计数字段也整体未知；只读检查原始有界响应，不改变既有对话JSON的接受规则。
- 各字段独立累计有效小计和有效报告次数，注明覆盖分母。所有字段覆盖全部已登记调用且无溢出才显示完整；仅部分字段或调用有效时显示部分；没有有效值时为未知。累计溢出后该字段保持未知，不回绕或截断为最大值，其他有效字段仍可显示。
- 用量字段异常不拒绝本来有效的模型对话，不新增请求、重试、设备动作或控制条发布。只有调用线程在收到原Future结果并复核原上下文后才能采纳报告；旧代次、停止或取消后的迟到结果不能加入当前统计。
- 暂停后原已采纳小计保留，旧在途回复不能补入新代次。结束统计沿原Controller终态冻结；清空和新任务隔离旧记录。界面继续使用已有前台每秒刷新和安全窗口，不增加持久化或诊断报告导出。

## 事前验收范围

核心回归验证字段类型、缺失、重复键、冲突、真实零值、累计溢出、一次票据、取消/暂停/旧代次及不可变快照。真实回环HTTP验证实际网关的合法回复、部分统计、未知统计和迟到回复，并覆盖合成探测共用入口；不把纯解析测试当作网络链路验收。

原生测试使用真实Controller、本地合成HTTP和受保护MainActivity，新增3项：完整多轮累计与零值；字段各自的部分覆盖、不推算总计；在途请求停止、迟到结果、清空和新任务隔离。原255项/API保留，精确身份已在运行前冻结为258项/API、八档2064项，其中新增24项。新页面采集记录为受保护未尝试，不新增清除安全标志的例外。

Android三案不直接覆盖溢出、畸形字段、重复键或暂停，这些由核心解析、所有权和真实HTTP测试覆盖。Android停止场景记录服务端实际准备及尝试写回，不能将写尝试当成客户端已消费；另有核心测试在网络线程已解析报告、Future尚未完成处设置闩锁，验证取消、暂停、配置失效及调用超时后的迟到结果不能补写统计。

整体录像沿普通Fixture操作流程独立录制一次，使用本地合成模型，不显示受保护用量页面，不能替代Token用量断言。录像失败非阻断，不为取得成功重复录制。
