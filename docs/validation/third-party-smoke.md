# 第三方应用开发探针

此探针使用未修改、未重新签名的官方应用 APK，在专用模拟器上检查实际界面流程。它补充合成应用测试，不属于常用应用总体兼容率、升级、真机或正式发布验收。第一版计算器样本的历史范围与结果保留在下文；第二版增加笔记应用并覆盖八档 API。

## 第二版固定样本

[版本化清单](third-party-app-set-lock.json)包含 Calculator 1.4.0 与 Notes 1.7.0，API 30、31、32、33、34、35、36、37，共两个应用 × 八个 API × 关闭/空闲两态，固定分母为 **32 个组合**。首次运行前全部标记未验证；缺失、失败与受保护截图不会从分母中移除。

| 应用 | 实际界面流程 | 独立结果检查 |
| --- | --- | --- |
| 计算器 | 从已安装包的桌面入口启动、清除旧算式、输入 `2 + 3 =` | 当前结果控件为 `5` |
| 笔记 | 从实际桌面入口启动，创建各状态不同的标题与正文，回到主页触发应用正常自动保存，停止旧进程并重新启动 | 新进程中的可见标题和完整正文与该状态的合成输入一致 |

探针不会写入目标应用数据库，也不会替应用实现保存。笔记的桌面入口由安装后的 PackageManager 解析，不从包名猜测；输入法只允许识别已配置的系统输入法并收起，随后仍要求操作和采集目标没有遮挡。没有改变 Agent 的生产工具、权限或确认策略。

Notes 安装包已在本地核对官方发布文件的大小、SHA-256、签名与 manifest，原始工具输出见[安装包检查记录](apk-inspections/notes-1.7.0/)。这一步没有安装或运行应用。每次设备测试仍重新核对下载文件和实际安装身份，不将新下载文件的签名自动当作可信基线。

当前工作流 `third-party-smoke.yml` 的 `mode=test` 使用第二版清单；`mode=archive` 按原测试源码和协议归档，历史第一版记录保持独立。每个 API 执行四项真实应用测试。第二版驱动、归档及既有回归共 **74 项本地 Python 测试通过**，独立测试 APK 构建与 lint 通过；设备实际结果见下文，脚本和构建通过不代表设备通过。

### 第二版首轮实际结果

源码 `3f4156e8` 的[运行40495646006](https://github.com/ecojust/Agent-OS/actions/runs/40495646006)完成全部32个组合：**22通过、10失败、零未运行**。计算器16/16通过；笔记6/16通过。API31四项全过；其他API均保留具体失败，没有删除应用、系统档位或失败状态。

笔记失败发生在探针前置检查：API30/32/36/37的关闭态尚未得到唯一可见标题；API33/34两态的新建流程与API35两态的启动流程拒绝了输入法窗口。实际窗口记录显示，键盘可能停在导航栏上方，也可能处于超出屏幕边界的过渡位置；原辅助器要求底边等于屏幕底部，不能代表这些平台的有效输入法几何。此结论来自失败记录，尚不表示修改后已通过。失败的状态未完成冷重启后的持久化验证。

[完整证据](../../screenshots/third-party-40495646006-1/)保留64个载荷、1,985,222字节、40张实际PNG和22条blocked采集记录，大小与SHA-256已独立核验。一个API31成功页面截图仍可见键盘，说明仅靠当时的无障碍窗口列表不能证明键盘动画已经消失；不把该截图用于证明截图遮挡保护或任意页面安全。测试只使用固定合成笔记，不含私人数据。

首轮后的测试辅助器修复保留原32个组合：标题为零个匹配时只读等待至多5秒，多个匹配仍拒绝；只对已核验的默认系统输入法允许有限的动画几何并收起，之后点击仍使用无遮挡路径。笔记截图增加固定输入法窗口身份与隐藏状态的有界检查，字段缺失、仍显示或动画未结束均记为blocked；该检查不等于窗口管理器与实际屏幕呈现的原子保证。测试APK和lint通过，设备复测待完成；没有修改原版应用、Agent生产窗口规则或历史证据。

### 第二版第二轮实际结果

源码 `5060f597` 的[运行40499117689](https://github.com/ecojust/Agent-OS/actions/runs/40499117689)完成相同32个组合：**26通过、6失败、零未运行**。计算器16/16通过，笔记10/16通过；API35/36/37四项全过。失败均保留在笔记样本中：API30关闭态的新建输入控件未找到、空闲态正文检查仍有输入法遮挡；API31关闭态与API33空闲态在收键盘时得到根窗口归属不匹配；API32关闭态的键盘未在5秒内退出；API34关闭态的新建点击仍被输入法遮挡。现有日志将空根与异包合并，不能据此断言存在其他应用。

[完整证据](../../screenshots/third-party-40499117689-1/)的56个载荷、1,911,940字节均通过两次独立大小和SHA-256核验。32张实际PNG全部来自计算器；笔记32次采集全部为blocked，原因是无法确认输入法已隐藏或动画已结束。因此本轮没有笔记无遮挡截图证据，不能把功能流程的10个通过推断为截图保护验证通过。后续修复仍保留原32组合、系统动画与未知遮挡拒绝，不修改已归档失败。

第二轮后，测试辅助器将笔记准备与动作绑定到同一份严格窗口/节点快照：只对未发布根、尚未出现的资源和已核验输入法做同一个5秒期限内的只读等待，连续600毫秒几何稳定后只执行一次动作；同一输入与读回上下文最多发送一次收键盘BACK。真正异包、未知遮挡和歧义仍立即拒绝，不重复创建或输入。WMS采集条件不放宽，只从既有读取增加至多5条固定枚举诊断，以定位字段缺失或仍显示的实际原因，不保存原始dump、标题或输入。辅助器APK与lint通过，原32组合待第三轮设备复测。

### 第二版第三轮实际结果与窄修复

源码`5468c411`的[运行40502976639](https://github.com/ecojust/Agent-OS/actions/runs/40502976639)保持32个组合：**25通过、7失败、零未运行**，计算器16/16、笔记9/16。七个失败均发生在新建标题输入前，API30关闭态已校验应用的窗口尺寸为空，其余六项落在尚未拆分的焦点/type/display检查；旧日志不能证明这些六项都是焦点未发布。原输入动作没有重发。

[原证据](../../screenshots/third-party-40502976639-1/)56载荷、2,366,519字节逐个大小与SHA-256通过两次核验；32实际PNG全部是计算器，笔记32次均blocked。新增128条固定WMS字段观察表明：32次最终样本中12次没有surface、三个可见谓词均false，却保留历史`mLastHidden=false`；另外20次surface仍shown，继续拒绝。没有用源码解释改写旧采集结果。

后续补丁只在已证明无surface且所有当前可见/进入动画谓词均否定时，允许合法的历史隐藏标记false；有surface分支保持严格，不放行上述20个可见样本。缺失、重复、冲突或未知字段仍拒绝。Notes准备把无焦点、尚无根包名及已校验应用的空尺寸作为原期限内的只读等待；明确错误type/display或异包继续拒绝，并输出固定元数据以区分原因。输入后的检查仍共用原5秒及最多一次BACK额度，绝不重发输入。APK与lint通过，原32个组合待第四轮实际复测。

## 第一版固定范围

- 安装包来源、版本、字节数、SHA-256、签名证书、API 和 ABI 固定在 [样本清单](third-party-calculator-lock.json)。下载、安装前和设备内的身份分别校验；不接受同名但不同签名的应用。
- API 30、35、37 三个环境；API 37 固定 Emulator 37.2.12，并在运行时复核版本。
- 每个环境保留两态结果：Agent 服务关闭，以及服务实际绑定但没有任务。测试读取实际绑定状态，不能只凭设置项判断开启成功。
- 独立测试 APK 通过公开测试接口操作算术界面，不压制无障碍服务，不增加 Agent 生产权限。没有账号、私人数据或支付操作。
- 分别记录每一步、真实结果、截图尝试、失败和未运行状态。截图只来自已核对身份的合成算术场景；保护窗口、未知前台或采集失败如实登记，不移除安全标记。
- Agent 执行态、正常更新及数据保留、真实手机和其他应用仍是未验证项。

## 构建与运行

```bash
./gradlew :compat-smoke:assembleDebug :compat-smoke:assembleDebugAndroidTest :compat-smoke:lintDebug
python3 -m unittest discover -s scripts -p 'test_third_party_smoke*.py'
```

在 master 上手动运行 `third-party-smoke.yml`，选择 `mode=test`。驱动仅允许该工作流的全新专用模拟器，拒绝连接个人手机或操作已经安装目标应用的设备。

测试结束后，以同一工作流的 `mode=archive` 和 `run_id` 归档。归档器核对源码、运行轮次、固定矩阵和文件校验值，保留失败、缺失及受保护截图，输出 `screenshots/third-party-<run>-<attempt>/` 和独立证据分支；审核后再合入主分支。

本模块首次本地验证：测试 APK 构建及 lint 通过，51 项探针/归档 Python 测试通过。设备结果需以实际运行及归档为准。
