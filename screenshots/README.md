# 测试截图记录

从本轮开始，Android 界面测试保存实际模拟器截图与逐项清单，按 CI 运行编号和 attempt 分目录，并提交到仓库。旧测试未采集的截图不补画。

- 截图仅来自独立合成测试应用或明确为空配置的 Agent OS 测试界面，禁止真实账号、密钥及用户页面。
- 产品的安全窗口设置保持不变；如拍摄空白控制台展示图，只有测试代码临时调整窗口标志，并在 `finally` 恢复。
- 安全窗口、不可观测页面或采集失败明确记录 `blocked` / `fail`，不把黑屏当成功截图。
- JVM、加密存储等无界面测试记录其结果和没有截图的原因，不使用无关屏幕冒充证据。
- 测试通过与截图成功分别记录；一个 PNG 不能证明应用兼容或任务完成。

每批记录应包含源码提交、系统 API、测试运行链接、时间、测试名称、结果、截图路径及采集状态。模拟器结果与真机验收分开统计。
